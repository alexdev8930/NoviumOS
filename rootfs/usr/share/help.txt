NoviumOS
---------

System Information:
- Architecture: x86_32 (Multiboot 1)
- Root Filesystem: POSIX tar initial ramdisk (initrd) mounted at /

Directory Layout:
- /dev : Device nodes and hardware interfaces
- /etc : System configuration and version information
- /mnt : Mount point for external filesystems
- /tmp : Temporary files
- /usr : Shared system files and documentation

Available Commands:
- help         : Show this help message
- clear        : Clear the console screen
- echo <text>  : Print arguments to the console
- pwd          : Print the current working directory
- cd <path>    : Change the current working directory
- ls [path]    : List directory contents
- cat <file>   : Print the contents of a file
- stat <path>  : Show file or directory metadata
