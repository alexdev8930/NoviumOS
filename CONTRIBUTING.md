# Contributing

This project is still early and mostly a personal learning project, so contributions are welcome but should stay simple and focused.

## Guidelines

- keep changes small and easy to understand
- favor clear code over clever code
- keep the project structure consistent with the existing layout
- avoid introducing unnecessary complexity early on

## Before submitting changes

- make sure your changes are relevant to the current goals of the project
- keep the README and project structure consistent with your work
- be clear about what you are trying to build or improve
