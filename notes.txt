[NOTES]

- PageSetRange() rounds reserved ranges outward to 4096-byte page boundaries, so the
  kernel reservation protects every page touched by [_kernel_start, _kernel_end), even
  if either symbol is unaligned. link.ld currently aligns both symbols, but allocator
  safety does not depend on that alignment.

- kprintf %d/%i now avoids the INT32_MIN overflow by printing the magnitude in an
  unsigned type instead of negating the signed value in place

- HEAP: HeapGrow now asks the page allocator for a run that starts at the highest
  recorded segment end, which acts as a growth hint rather than a hard adjacency
  requirement. block and segment boundary checks use the owning segment for each
  block, so the heap no longer depends on one global tail pointer for correctness.
