[NOTES]

- kfree() crashes on NULL: it does pointer arithmetic on addr without checking
  for NULL first, so free(NULL) computes a bogus address and dereferences
  b->Meta.Magic. Needs an early "if (addr == 0) return;".

- typo in init/main.c: "OK: Scheduling Init Succesfull" should be
  "Successfully".

- shell silently drops input when the line is full: once len hits
  SHELL_LINE_MAX - 1, extra keystrokes are just thrown away with no feedback.
  Should at least beep or refuse the input so the user knows the line is full.
